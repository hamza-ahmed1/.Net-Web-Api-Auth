Clean API list

Base URL: {BASE_URL} (e.g. https://localhost:7179)

Auth
- POST {BASE_URL}/api/auth/register — Register user
- POST {BASE_URL}/api/auth/login — Login (returns access token; sets refreshToken cookie)
- POST {BASE_URL}/api/auth/refresh — Refresh access token (uses refreshToken cookie)
- POST {BASE_URL}/api/auth/logout — Logout (requires Authorization)

Roles
- GET {BASE_URL}/api/roles — List roles
- POST {BASE_URL}/api/roles — Create role (body: raw string or JSON with role name)

Admin / Teachers
- POST {BASE_URL}/api/admin/teachers — Create teacher
- PUT {BASE_URL}/api/admin/teachers — Update teacher
- GET {BASE_URL}/api/admin/teachers/{teacherId} — Get teacher by id
- DELETE {BASE_URL}/api/admin/teachers/{teacherId} — Delete teacher
- POST {BASE_URL}/api/admin/teachers/restore/{teacherId} — Restore teacher
- POST {BASE_URL}/api/admin/teachers/promotion/{teacherId} — Promote to HOD
- POST {BASE_URL}/api/admin/teachers/demotion/{teacherId} — Demote to teacher

- DELETE {BASE_URL}/api/student/{studentId} — Delete student
- GET {BASE_URL}/api/student/export — Export students (Excel)

Attendance
- POST {BASE_URL}/api/attendance — Mark single attendance
- POST {BASE_URL}/api/attendance/bulk — Mark bulk attendance
- GET {BASE_URL}/api/attendance/{attendanceId} — Get attendance record
- GET {BASE_URL}/api/attendance/course/{teacherSectionCourseId}?date={yyyy-MM-dd} — Get course attendance by date
- GET {BASE_URL}/api/attendance/student/{studentId}?courseId={id}&from={date}&to={date} — Get student attendance history
- GET {BASE_URL}/api/attendance/student/{studentId}/courses — Get active courses for student
- PUT {BASE_URL}/api/attendance/{attendanceId} — Update attendance
- DELETE {BASE_URL}/api/attendance/{attendanceId} — Delete attendance
- GET {BASE_URL}/api/attendance/course/{teacherSectionCourseId}/summary?from={date}&to={date} — Course attendance summary

Exams
- POST {BASE_URL}/api/exam — Create exam

Notes
- Use Authorization: Bearer {accessToken} for protected endpoints.
- Login sets an HttpOnly refreshToken cookie; call POST /api/auth/refresh to obtain a new access token.
